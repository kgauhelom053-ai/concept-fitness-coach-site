# Ridge Fit — concept fitness coach website

One-page website concept for a **fictional** online personal training / strength coaching brand (**Ridge Fit**, Coach Jordan Hale).

**Concept design — not a real client.** The coach, prices, testimonials and contact details are placeholders for portfolio sample work.

## Includes
- Hero with clear CTA
- Programs / packages with prices
- How it works (3 steps)
- About the coach
- Sample testimonials (clearly labelled as sample text)
- FAQ
- Contact / booking form (demo only — no backend)

## Stack
Plain HTML/CSS/JS, no build step. Pure CSS + SVG visuals (no stock photos).

Designed by Kgauhelo Mokoena.
